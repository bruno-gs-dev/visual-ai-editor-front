# Visual AI Editor — Frontend

Landing page e playground interativo do **Visual AI Editor**.

## Sobre

O Visual AI Editor é uma ferramenta que permite editar HTML com IA em linguagem natural. Selecione qualquer elemento, descreva a mudança, e a IA atualiza seu código respeitando o seu Design System.

## Como usar

Basta abrir o `index.html` no navegador.

## Stack

- HTML / CSS / JS vanilla (sem dependências externas)
- Fonts: Space Grotesk, Inter, JetBrains Mono (Google Fonts)
