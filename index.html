O fluxo

Tres passos, um round-trip.

O editor manda so o contexto necessario pra IA, valida a resposta e aplica a mudanca preservando a estrutura do seu projeto.

01 · Selecione

Clique, arraste ou lasso

Um clique num elemento, um retangulo sobre varios, ou um traco livre em volta de um grupo.

02 · Descreva

Em linguagem natural

"Aumente o padding do botao e use a cor primaria." O modelo recebe o seu DESIGN.md junto.

03 · Revise & aplique

Voce aprova a mudanca

Confira o resultado, aplique — e o save vira um diff de 1 linha no arquivo de origem, com backup automatico.

Recursos

O que vem na caixa.

Feito pra iterar em projetos que ja existem — nao pra gerar tudo do zero.

Selecao visual

Clique, arraste uma area ou desenhe um laco livre em volta dos elementos.

Um clique seleciona um elemento. Arrastar seleciona varios. O laco livre pega ate elementos soltos — todos mandados numa unica requisicao.

clique p/ detalhes

Edicoes com IA

Descreva o que quer mudar em linguagem natural — o modelo recebe seu Design System junto e aplica com precisao.

Qualquer OpenAI-compatible API funciona. Groq, OpenAI, Anthropic, Gemini, Ollama, LM Studio. A instrucao vai junto com o HTML selecionado, o DESIGN.md, e o CSS relevante.

clique p/ detalhes

Design System na regua

A IA segue seu DESIGN.md. E o servidor confere cada resposta — cores fora da paleta sao barradas antes de chegar no seu codigo.

17 cores, 11 secoes recomendadas. O design:lint scaneia todo o projeto. O design:check mede cobertura. Tudo automatizado.

clique p/ detalhes

Saves cirurgicos

Aplica um patch no arquivo com diffs de 1 linha. Backup automatico antes de cada save.

Pares {before, after} localizam o trecho no source e substituem so aquilo. Formatacao, comentarios e indentacao intactos no resto. Max 100 backups por arquivo.

clique p/ detalhes

Undo / Redo

Ctrl+Z / Ctrl+Y — instantaneo e sem gastar nenhum token.

Desfazer/restaurar e 100% client-side. Nao chama a API, nao gasta token. O estado anterior fica em memoria. Funciona em qualquer page.

clique p/ detalhes

Framework-safe

Em React, Vue ou Angular, cada edicao visual gera um manifesto que um agente de IA aplica no source real — nada e escrito por cima do render.

Claude Code, Cursor ou similar le .ai-editor/pending-changes.md e aplica cada mudanca no JSX/template original. Source detectado automaticamente via _debugSource, __file ou data-ai-source.

clique p/ detalhes

Framework-agnostic

HTML estatico, React, Angular, Vue — ou qualquer framework.

O server serve qualquer .html e injeta o editor automaticamente. Framework pages usam o handoff. Funciona com Vite, Next, Angular CLI, ou qualquer dev server.

clique p/ detalhes

UI EN / pt-BR

Detectada pelo <html lang>, ou definida explicitamente.

Toda a UI do toolbar — botoes, mensagens, warnings — segue o idioma da page. Funciona tanto no client quanto no server.

clique p/ detalhes

Visualizador do DESIGN.md

Abra a referencia do seu design system num modal, dentro do proprio editor.

Renderiza o DESIGN.md com marked (bundled). Cores, tipografia, componentes, regras — tudo acessivel sem sair da toolbar.

Guarda de paleta

A cor errada nao passa.

O DESIGN.md entra no system prompt em toda edicao. E o servidor valida cada resposta contra a paleta: cores fora do design system sao bloqueadas antes de chegar no seu codigo.

O botao Aplicar mesmo assim reaproveita o HTML que o modelo ja devolveu. Sobrescrever custa zero tokens extras.

Salvando as edicoes

Dois modos, escolhidos por voce.

O botao Salvar faz uma de duas coisas bem diferentes, dependendo da pagina.

Linha de comando

Zero-config pra comecar.

Um comando sobe o servidor, abre o navegador e injeta a toolbar em toda pagina .html servida.

bash
$ npx visual-ai-editor start

[ai-editor] server at http://localhost:3000
[visual-ai-editor] Editor no ar: http://localhost:3000
[visual-ai-editor] Toolbar injetada ✓
start

Sobe o editor no diretorio atual (padrao). Config interativa na primeira vez.

config

Configura o provider de IA — interativo ou via flags (--provider, --show).

design:init

Escreve o DESIGN.prompt.md — um roteiro guiado pra gerar seu DESIGN.md.

design:check

Diz quais das 11 secoes recomendadas ja existem no seu DESIGN.md.

design:lint

Acha cores fora da paleta no CSS/HTML/JS do projeto.

agents:init

Instala ou atualiza o AGENTS.md (normalmente automatico).

Seguranca

Ferramenta de dev, por padrao.

Pensada pra desenvolvimento e staging

A API fica sem autenticacao a menos que voce defina apiToken. O servidor estatico bloqueia .git, node_modules e .env*.

Em NODE_ENV=production sem token, o servidor se recusa a iniciar — em vez de expor um editor silenciosamente. Pra producao de verdade, coloque atras da sua camada de auth (proxy, VPN) e use o apiToken como segunda camada.

Instale e selecione.
